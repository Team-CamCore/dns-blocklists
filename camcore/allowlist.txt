# CamCore DNS allow-list
#
# Names CamCore must never block. The publisher removes every matching name
# from the upstream data before blocklist.txt is published, and the source-health
# check fails if a published feed ever contains one.
#
# Syntax, one entry per line:
#   host.example.com    that exact name only
#   *.example.com       example.com and every name beneath it
#
# Entries are lower-case and sorted within each section. Use *. only where no
# name under the namespace is a tracker or telemetry host. Where the parent
# domain also serves telemetry (github.com, plex.tv, ubuntu.com), list the
# exact service hosts instead. Record the reason in the change record.
#
# Sections are grouped by the CamCore service that depends on them. The
# CamCore Active Service Register is the source for what CamCore uses.
